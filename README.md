# Educational Management System – Domain Model

## 📘 Overview

This repository presents the **Domain Model** for an Educational Management System. The model is depicted in the `Domain Model.svg` file, illustrating the key entities and their relationships within the system.

## 🖼️ Diagram

![Domain Model Diagram](Domain%20Model.svg)

## 🧠 Key Entities

* **Student**: Represents individuals enrolled in the educational institution.
* **Course**: Denotes the various courses offered.
* **Instructor**: Faculty members responsible for teaching courses.
* **Department**: Academic divisions organizing courses and programs.
* **Enrollment**: Records of students enrolling in courses.

* `Domain Model.svg`: Visual representation of the domain model.
